# 🚀 AETHER-QKD: Deep-Space Quantum Key Distribution & Enigma Cryptography Suite

An advanced, cinematic dual-layer security platform built for the **NASA Space Apps Challenge**, combining futuristic Quantum Key Distribution (BB84 protocol) for interplanetary communication links with historical Enigma code-breaking and interception labs.

---

## 🌟 Overview
As humanity pushes deeper into the solar system, secure long-distance communication is critical. Traditional encryption methods face vulnerabilities from upcoming quantum computers, and space telemetry links are constantly exposed to cosmic noise and eavesdropping. 

**AETHER-QKD** solves this by bridging two eras of cryptography:
1. **Quantum Key Distribution (BB84 Protocol):** Uses polarized photon transmission between a deep-space probe (Alice) and an Earth station (Bob) to generate unbreakable secret keys, leveraging the Heisenberg Uncertainty Principle to detect active eavesdroppers (Eve) via real-time **Quantum Bit Error Rate (QBER)** tracking.
2. **Enigma Intercept Lab:** A historical rotor-based cryptographic code-breaking lab allowing mission operators to encrypt tactical telemetry and crack intercepted rogue spacecraft ciphertexts.

---

## ✨ Key Features
- **Cinematic Mission Control Interface:** Features a live-looped background video feed with high-contrast tactical styling and glassmorphism UI elements.
- **BB84 Simulation Engine:** Simulates quantum photon generation, random basis sifting (+ and ×), and transmission efficiency metrics.
- **Live QBER Security Audit:** Automatically audits error rates and triggers security alerts if QBER exceeds the strict **11% cryptographic security threshold**.
- **Enigma Rotor Code-Breaking Lab:** Fully interactive cipher encoder and cracker using adjustable rotor offsets and plugboard permutations.

---
